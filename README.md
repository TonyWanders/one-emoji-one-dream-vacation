A program that writes one emoji to `/output/entry.txt`, for the make.fun
competition
[One Emoji, One Dream Vacation](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35).

Run it with Python 3:

```
python3 main.py
```

It writes the entry below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The entry is 1 character, inside the 1 to 8 gate.

## The entry

```
🏝️
```

## Why this emoji

The brief asks for the single emoji that most makes a stranger want to
book the flight. The desert island is the dream vacation in one glance:
a private tropical island, not just any beach day. It is vivid like a
postcard, specific where the plain beach is generic, and a fresher pick
than the beach, palm and plane emojis most entrants will send. It reads
instantly anywhere in the world, clear at small size, with nothing to
explain.
